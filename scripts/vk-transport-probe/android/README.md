# Android native VK probe

Это временная диагностическая программа для проверки нативного `dart:io`
клиента Android. Она не является частью LocalTube и не встраивается в APK
приложения. Ключ сообщества вводится на телефоне, не прошивается в APK, не
сохраняется в отчёте и не отправляется на сервер LocalTube.

## Что проверяет

- `groups.getById` и контрольный запрос production API;
- `messages.send(peer_ids=...)` с сохранением подтверждённого CMID;
- чтение ответа через `messages.getByConversationMessageId`;
- повтор с тем же логическим request ID без второй подготовки;
- `GET_STATUS` после нового запроса;
- получение вложенного MP4, размер, SHA-256 и HTTP Range с начала и смещения 17;
- сохранение ответа до продвижения курсора и восстановление после нового запуска.

Каталог роликов синтетический. Проба не утверждает работу LocalTube API,
встроенного LocalTube-плеера, больших файлов или обновления истёкших ссылок.

## Ответчик на доверенном сервере

Ответчик загружает маленький MP4 в существующую тестовую беседу и отвечает на
сообщения из приложения. Запускайте его на доверенном сервере, где уже лежит
настройка пробника; ключ не передавайте в командной строке:

```bash
python3 scripts/vk-transport-probe/android_server.py --timeout 900
```

Для другого файла используйте `--video /absolute/path/sample.mp4`. Состояние
записывается в `${XDG_STATE_HOME:-~/.local/state}/localtube-vk-probe/android-server.json`
с правами `600`; он содержит дескриптор вложения и журнал запросов.

## Проверка на Android

1. Установите APK диагностической программы, собранный внешним CI.
2. При активных белых списках откройте приложение, укажите `ID сообщества
   242343342`, `peer_id 2000000001`, вставьте ключ и включите флажок белых списков.
3. Нажмите «Проверить команды и файл». Успешный результат должен включить
   round-trip, duplicate, status, SHA-256 и Range.
4. Нажмите «Отправить ответ с задержкой», полностью закройте приложение на
   20 секунд, откройте снова, вставьте ключ и нажмите «Получить сохранённый
   ответ». Отчёт должен показать другой runtime/PID и успешное получение.
5. Не отправляйте ключ вместе с отчётом. Пришлите только JSON, скопированный
   кнопкой «Скопировать отчёт», и укажите оператора/время; подписанные URL в
   отчёт не входят.

После проверки включите авиарежим и нажмите «Проверить файл без сети»; это
проверяет контрольную сумму файла в приватном кэше приложения. Само приложение
не проигрывает и не экспортирует видео; внешний и офлайн-просмотр через VK
проверены пользователем отдельно.
